# Memory Index

- [WebGPU preprocessing warnings are red herrings](project_webgpu_preprocessing_warning.md) — Bevy 0.18 "preprocessing are limited" = PreprocessingOnly (still on GPU), "pipeline wasn't ready" is warn_once at startup; neither is per-frame CPU cost

- [Composite "sign-dependent position" is a non-bug](project_composite_sign_position_nonbug.md) — transform/rapier math is sign-symmetric; opposite-sign XZ symptom can't come from composition; real defects = collider replacement (trigger_zone ball lost to compound) + nested RigidBody::Fixed
- [UI click-blocking = coverage + z-order, not Button presence](project_ui_pick_blocking.md) — Bevy 0.18 UI nodes block lower picks by default but only over the rect they cover; non-full-screen panel + GlobalZIndex(51) doesn't block buttons outside it; targeting bypasses UI picking entirely and needs a panel_open guard
- [FocusPolicy::Block required for UI blockers](project_focuspolicy_block_required.md) — ui_focus_system (Interaction path) does NOT block on z-index alone; Node defaults FocusPolicy=Pass, so a blocker needs explicit FocusPolicy::Block or clicks pass through to buttons beneath
