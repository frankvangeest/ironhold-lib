# Memory Index

- [WebGPU preprocessing warnings are red herrings](project_webgpu_preprocessing_warning.md) — Bevy 0.18 "preprocessing are limited" = PreprocessingOnly (still on GPU), "pipeline wasn't ready" is warn_once at startup; neither is per-frame CPU cost
- [Per-frame Transform writes dirty nameplate subtrees](project_changedetection_transform_writes.md) — world_label_screen_pos_system writes Transform.translation unconditionally every frame, re-propagating to all Text2d/Mesh2d children; guard it like the font/visibility writes
- [Composite "sign-dependent position" is a non-bug](project_composite_sign_position_nonbug.md) — transform/rapier math is sign-symmetric; opposite-sign XZ symptom can't come from composition; real defects = collider replacement (trigger_zone ball lost to compound) + nested RigidBody::Fixed
- [UI click-blocking = coverage + z-order, not Button presence](project_ui_pick_blocking.md) — Bevy 0.18 UI nodes block lower picks by default but only over the rect they cover; non-full-screen panel + GlobalZIndex(51) doesn't block buttons outside it; targeting bypasses UI picking entirely and needs a panel_open guard
- [FocusPolicy::Block required for UI blockers](project_focuspolicy_block_required.md) — ui_focus_system (Interaction path) does NOT block on z-index alone; Node defaults FocusPolicy=Pass, so a blocker needs explicit FocusPolicy::Block or clicks pass through to buttons beneath
- [target_indicator_system double-despawn](project_target_indicator_double_despawn.md) — two loops over one `existing` query snapshot + deferred despawn + no dedup = ring despawned twice ("generation 1" warning) when target dies same frame owner retargets; pre-existing, fix with HashSet dedup or try_despawn
- [Double-despawn bugs are untestable by ECS state](project_idempotent_despawn_untestable_by_state.md) — deferred despawn is idempotent (warn only, no panic, no state change); a regression test asserting entity count/no-panic passes with the bug present; needs log capture to detect
- [stat_display change-detection guards & .as_mut()](project_stat_display_changedetection_asmut.md) — a per-frame guard is defeated if you .as_mut()/get_mut before the value comparison; DerefMut marks Changed regardless (world_icon_bar_update_system does this; world_pixel_bar_update_system reads immutably first, correctly)
