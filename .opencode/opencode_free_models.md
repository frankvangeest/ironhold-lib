## How This List Was Made

### 1. OpenCode Zen Models
- Fetched via: `GET https://opencode.ai/zen/v1/models`
- The API returns all models in the OpenCode Zen catalog
- Models with "free" in the `id` field or owned by "opencode" are included
- File: `opencode_zen_models.txt` (binary JSON saved from PowerShell fetch)

### 2. OpenRouter Free Models
- Scraped from: `https://openrouter.ai/collections/free-models`
- Parsed model cards from the HTML page
- Each model entry includes: provider/name, context window, token quota, ranking position, and use case description
- File: `openrouter_free_models.html` (or could be parsed programmatically)

### 3. Rating Criteria
Models were rated across these agent task categories:
| Category | Description |
|---|---|
| **Coding** | Code generation, debugging, refactoring, agentic software engineering |
| **Reasoning** | Multi-step logic, planning, mathematical reasoning |
| **Analysis** | Code review, documentation, pattern analysis |
| **Exploration** | Codebase exploration, grep/grep equivalents, read-only tasks |
| **Creative** | Writing, brainstorming, design alternatives |
| **Budget** | Cost sensitivity (all are "free" on OpenRouter, but may have different Zen access) |

### 4. Rating Scale
- ⭐⭐⭐⭐⭐ **Excellent** - Top-tier for this task, comparable to paid models
- ⭐⭐⭐⭐ **Very Good** - Strong performer, may have limitations
- ⭐⭐⭐ **Good** - Usable for most cases, some caveats
- ⭐⭐ **Fair** - Works for simple tasks, avoid complex work
- ⭐ **Poor** - Avoid for this task category

## Regenerating This List

To regenerate this list when free models change:

### Option A: Manual Re-fetch
```bash
# 1. Fetch OpenCode Zen models
curl -s https://opencode.ai/zen/v1/models > opencode_zen_models.json

# 2. Fetch OpenRouter free models (requires parsing HTML)
# Use a script or browser to scrape https://openrouter.ai/collections/free-models
# Save the relevant model cards

# 3. Update this markdown file with new model data
# Re-rate models as needed
```

### Option B: Automated Script (Python example)
```python
import requests
import json

# Fetch OpenCode Zen
zen_resp = requests.get("https://opencode.ai/zen/v1_models")
zen_models = zen_resp.json()

# Filter for free models
free_zen = [m for m in zen_models if "free" in m.get("id", "").lower()]

# Fetch OpenRouter (would need HTML parsing or API)
# OR free list is at: https://openrouter.ai/api/v1/models?free=true

# Generate markdown...
```

### Option C: Update Script Included
- Add a script to `.opencode/scripts/` that fetches both sources
- Run `python .opencode/scripts/update_free_models.py`
- Overwrites `.opencode/opencode_free_models.md`

real `opencode.json` key — the correct key is singular `"agent"`. A top-level `"model_routing"`

model in this catalog. The real, working config for this project is `.opencode/opencode.json`

## Model Availability Notes

1. **OpenRouter free models**: May have rate limits, daily quotas, or require account signup. Check OpenRouter status for current availability.

2. **OpenCode Zen free models**: Available when running OpenCode with Zen backend; no external API keys needed.

3. **Model variants**: Some models have `#high`, `#fast`, or other variants specified after `#` in the model ID.

4. **Context windows**: Vary significantly; check each model's specific limits for long codebase analysis.

5. **Licensing**: OpenRouter models follow their respective provider licenses; OpenCode Zen models are for local/OpenCode usage.

6. **Rate limiting**: Free models may have stricter rate limits than paid tiers; batch operations may be limited.
